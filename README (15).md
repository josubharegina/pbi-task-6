# Healthcare Visualization Dashboard

## 📌 Project Overview

The Healthcare Visualization Dashboard is a data visualization project created using **Microsoft Power BI** to analyze healthcare data. It presents important information about patient demographics, billing amounts, admission types, medical conditions, and insurance providers through interactive charts and visual elements.

The dashboard helps users understand healthcare data easily and identify useful insights from different categories.

## 🎯 Objectives

- Analyze patient demographics based on gender and age groups.
- Display the average and total billing amounts.
- Understand admission patterns across different admission types.
- Visualize patient-related information and insurance provider categories.
- Present healthcare data in a clear and interactive dashboard.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization.
- **Power Query Editor** – Data cleaning and transformation, if used in the project.
- **Healthcare Dataset** – Patient, admission, billing, and insurance-related information.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Average Billing Amount
- Earliest Admission Date
- Patient-related count or total
- Total Billing Amount

### 2. Gender Analysis
A stacked bar chart displays the gender distribution across different age groups.

### 3. Age Group Analysis
A table compares female and male counts across age groups and displays the totals.

### 4. Admission Type Analysis
A line chart visualizes admission counts across Routine, Emergency, and Urgent admission types.

### 5. Medical Condition and Insurance Analysis
A doughnut chart presents the relationship between medical condition counts and insurance provider information by admission type.

### 6. Insurance Provider Filter
Users can filter the dashboard by insurance providers such as Blue Cross, Medicare, and UnitedHealthcare, and by age group where supported.

### 7. Billing Analysis
An area chart compares billing-related measures across patient categories.

## 💡 Key Insights

- The dashboard provides a quick overview of billing amounts and patient-related metrics.
- Gender distribution can be compared across age groups.
- Admission patterns can be examined across different admission types.
- Insurance providers and billing measures can be explored through visualizations and filters.

*Note: The insights displayed depend on the dataset, data relationships, and Power BI calculations.*

## ⚙️ How to Use

1. Open the Power BI dashboard file (`.pbix`) in Microsoft Power BI Desktop.
2. Load or refresh the healthcare dataset if required.
3. Explore the KPI cards and charts.
4. Use the available filters to analyze specific insurance providers or age groups.
5. Compare the displayed values to understand healthcare data patterns.
